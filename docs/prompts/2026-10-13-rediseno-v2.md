## Decisiones resultantes

| Tema | Decisión | Motivo |
|---|---|---|
| Música | Pista propia creada con IA, botón para activarla | Derechos de Nintendo y bloqueo de audio automático en los navegadores |
| Contacto | FormSubmit con respuesta automática y página de gracias | Funciona en GitHub Pages sin servidor propio |
| Chatbot | Cloudflare Worker + Workers AI | La clave no puede estar en el navegador |
| Componentes | Web Components para cabecera y pie | Reutilizar sin herramientas de build |
| Zelda | `api.hyrule-compendium.com` | El dominio antiguo de Heroku ya no existe |
| Anime | Animechan (`api.animechan.io/v1`) | Elegida por mí; 100 peticiones al día gratis |
